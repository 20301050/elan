# Élan · Studio multi-activités

Site web de la salle de sport **Élan** (boxe, HIIT, cardio, renforcement, Pilates, yoga), conçu et piloté avec l'IA par **Malgorzata Kieliszek**, cheffe de projet digital & e-merchandising.

## Pages
- `index.html` : Accueil
- `activites.html` : Nos activités
- `planning.html` : Planning (filtres par activité et par coach)
- `tarifs.html` : Tarifs et questions fréquentes
- `coachs.html` : Nos coachs
- `actualites.html` : Actualités (dont l'article nutrition)
- `contact.html` : Contact et formulaire
- `mentions-legales.html` : Mentions légales

Chaque page a une version **ordinateur** (écran de 1200 px et plus) et une version **mobile** avec menu.

## Mettre le site en ligne avec GitHub Pages
1. Créer un nouveau dépôt sur GitHub (par exemple `elan`).
2. Glisser tout le contenu de ce dossier dans le dépôt (bouton **Add file › Upload files**), puis **Commit changes**.
3. Aller dans **Settings › Pages**, choisir la branche `main` et le dossier `/ (root)`, puis **Save**.
4. Après une ou deux minutes, le site est en ligne à l'adresse `https://ton-pseudo.github.io/elan/`.
